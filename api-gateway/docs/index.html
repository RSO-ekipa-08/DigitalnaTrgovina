API Gateway Documentation

Pregled

API Gateway je centralna vstopna točka za vse mikrostoritve v sistemu. Skrbi za usmerjanje zahtev, avtentikacijo uporabnikov in proxy komunikacijo z ostalimi storitvami.

Javni Endpointi

Health Check

GET /health

Endpoint za preverjanje zdravja storitve.

Odgovor:

{
    "status": "healthy"
}

Prijava

GET /login

Endpoint za prijavo uporabnika. Preusmeri na Auth0 prijavno stran.

Query parametri:

Parameter Opis Obvezen
redirect_url URL za preusmeritev po uspešni prijavi Ne

Callback

GET /callback

Callback endpoint za Auth0 avtentikacijo.

Query parametri:

Parameter Opis Obvezen
code Avtorizacijska koda od Auth0 Da

Odgovor: HTML stran z JWT žetoni in profilom uporabnika

Odjava

GET /logout

Endpoint za odjavo uporabnika.

Uporabniški profil

GET /user

Endpoint za prikaz uporabniškega profila.

Zahteva avtentikacijo: Da

API Proxy Endpointi

App Service API

ANY /api/app/*

Proxy za App Service API. Podpira naslednje operacije:

  • SearchApplications - iskanje aplikacij
  • ListCategories - seznam kategorij

Primer zahteve za iskanje aplikacij:

POST /api/app/app.v1.ApplicationService/SearchApplications
{
    "query": string,
    "category": string,
    "minPrice": number,
    "maxPrice": number,
    "minAndroidVersion": string,
    "pagination": {
        "page": number,
        "pageSize": number
    },
    "sort": [
        {
            "field": string,
            "ascending": boolean
        }
    ]
}

Reviews Service API

POST /api/reviews/graphql

Proxy za Reviews Service GraphQL API. Omogoča poizvedbe in mutacije za upravljanje z ocenami aplikacij.

Primer GraphQL poizvedbe:

POST /api/reviews/graphql
{
    "query": """
    query GetReviews($appId: ID!) {
        reviews(appId: $appId) {
            id
            rating
            comment
            userId
            createdAt
        }
    }
    """,
    "variables": {
        "appId": "123"
    }
}

Headers:

Header Opis Obvezen
Content-Type application/json Da
Authorization Bearer {jwt_token} Da (za mutacije)

Avtentikacija

API Gateway uporablja Auth0 za avtentikacijo uporabnikov. Proces avtentikacije:

  1. Uporabnik je preusmerjen na /login endpoint
  2. Uporabnik je preusmerjen na Auth0 prijavno stran
  3. Po uspešni prijavi je uporabnik preusmerjen nazaj na /callback endpoint
  4. API Gateway preveri avtentikacijsko kodo in pridobi JWT žetone
  5. Uporabnik je preusmerjen nazaj na aplikacijo z veljavnimi žetoni
